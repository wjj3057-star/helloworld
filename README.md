# 문제집 스캐너

푼 문제집을 여러 장 찍어서 **선생님께 보낼 PDF 한 개**로 만들어 주는 웹앱입니다.

사진 30장을 카톡에 하나씩 올리는 대신, 찍고 → 자동 보정 → PDF 한 개로 공유하면 끝입니다.

- 종이 영역을 **자동으로 찾아 반듯하게 폅니다** (비스듬히 찍어도 됨)
- **그림자와 조명 얼룩을 지워** 글씨를 또렷하게 만듭니다 (빨간펜 채점 표시는 색 그대로 유지)
- 페이지 **순서를 바꾸고** 필요 없는 장은 지울 수 있습니다
- **PDF 한 개**로 묶어 카톡·메일로 바로 공유합니다

설치할 것도, 회원가입도, 서버도 없습니다. 사진은 **기기 밖으로 나가지 않습니다.**

## 쓰는 법

`index.html` 파일 하나가 전부입니다. 브라우저로 열기만 하면 됩니다.

**휴대폰에서 쓰려면** GitHub Pages로 올려두고 주소를 즐겨찾기 해두는 게 가장 편합니다.

1. 저장소 **Settings → Pages → Source: `main` 브랜치 선택**
2. 잠시 뒤 나오는 `https://<아이디>.github.io/<저장소이름>/` 주소를 휴대폰에서 열기
3. 브라우저 메뉴에서 **홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다

> 연속 촬영(카메라 바로 쓰기)은 브라우저 보안 정책상 **https 주소에서만** 동작합니다.
> 파일을 직접 열었을 때(`file://`)는 자동으로 휴대폰 기본 카메라 앱을 띄우는 방식으로 넘어갑니다.

### 작업 순서

1. **연속 촬영** — 셔터를 계속 눌러 여러 장을 이어서 찍습니다. 찍는 동안 뒤에서 알아서 보정됩니다.
   이미 찍어둔 사진이 있으면 **불러오기** 로 한 번에 여러 장 선택하면 됩니다 (파일 이름순으로 정렬됩니다).
2. 썸네일에서 순서를 확인합니다. `◀` `▶` 로 순서 변경, `🗑` 로 삭제.
3. 잘린 부분이 이상하면 썸네일을 눌러 **네 모서리를 손으로 끌어** 맞춥니다.
4. **PDF 만들기** — 공유 창이 뜨면 카톡·메일로 바로 보냅니다. (공유를 지원하지 않는 환경에서는 파일로 저장됩니다.)

### 설정 (⚙)

| 항목 | 설명 |
|---|---|
| 파일 이름 | `수학문제집_2026-07-25.pdf` 처럼 저장됩니다 |
| 최대 용량 | 메일 첨부 제한 등에 맞춰 여러 개로 나눠 저장합니다 (`0` = 나누지 않음) |
| 기본 보정 | **문서**(기본) / **흑백 강조**(글씨 진하게) / **원본**(보정 안 함) |
| 화질 | 가벼움 / 보통 / 선명 |

작업 중인 페이지는 브라우저에 자동 저장되어, 실수로 창을 닫아도 다시 열면 그대로 남아 있습니다.

## 어떻게 동작하나

외부 라이브러리 없이 전부 직접 구현되어 있습니다 (`index.html` 한 파일).

1. **종이 찾기** — 밝기 히스토그램에서 Otsu 임계값을 구해 밝은(종이) 영역을 분리하고,
   가장 큰 덩어리의 극점(`x+y`, `x−y`의 최소·최대)으로 네 꼭짓점을 잡습니다.
2. **펴기** — 그 사각형을 직사각형으로 보내는 호모그래피를 8×8 연립방정식으로 풀고,
   결과 픽셀마다 원본을 역방향으로 이중선형 보간해 채웁니다.
3. **비율 복원** — 변 길이 평균만 쓰면 원근에 눌린 비율이 그대로 남습니다.
   직사각형이라는 조건(`b1·b2=0`, `|b1|/|b2|`=비율)에서 초점거리를 역산해 실제 종이 비율을 되살립니다.
4. **그림자 제거** — 적분영상으로 국소 평균 밝기(=종이 배경)를 구한 뒤 나눠 줍니다.
   채널마다 같은 배경값으로 나누기 때문에 **빨간펜 같은 색은 색을 유지**합니다.
5. **PDF 생성** — JPEG를 `DCTDecode` XObject로 넣어 PDF 1.4 구조(xref 테이블 포함)를 직접 씁니다.

## 정확도

합성한 시험 이미지(기울어진 종이 + 조명 얼룩)로 측정한 결과입니다.

**종이 자동 감지** — 1100×1500 사진에서 꼭짓점 오차 최대 **7.5px**

**기울기 보정** — 같은 사진을 보정한 것과 안 한 것 비교

| | 보정함 | 보정 없음 |
|---|---|---|
| 글줄 좌우 기울기 | **-1px** | -54px |
| 글줄이 애매하게 걸친 행 | **2.2%** | 86.4% |

**종이 비율 복원** — 실제 핀홀 카메라로 투영한 사각형으로 검증 (실제 비율 0.720)

| 촬영 각도 | 이 프로그램 | 변 길이 평균만 쓸 때 |
|---|---|---|
| 약간 기울임 | **0.720** (0.0%) | 0.725 (0.8%) |
| 많이 기울임 | **0.720** (0.0%) | 0.731 (1.5%) |
| 세로로만 기울임 | **0.752** (4.4%) | 0.797 (10.7%) |

마지막 경우는 위·아래 변이 화면에서 평행해져 초점거리를 원리적으로 구할 수 없습니다.
이때는 휴대폰 표준 화각(약 70°)을 가정하며, 가정이 ±20% 빗나가도 비율 오차는 4% 안쪽입니다.

## 알아둘 점

- 종이가 **배경보다 밝아야** 자동 감지가 잘 됩니다. 어두운 책상이나 바닥에 놓고 찍으세요.
- 종이가 화면을 거의 꽉 채우면 자를 것이 없다고 보고 그대로 씁니다.
- 자동 감지가 빗나가면 썸네일을 눌러 **직접 모서리를 맞추면** 됩니다. (`자동 감지` / `전체 사용` 버튼도 있습니다)
- 아주 심하게 기울여 찍으면 글씨가 뭉개집니다. 가능하면 위에서 반듯하게 찍는 게 좋습니다.
